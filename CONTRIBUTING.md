# Contributing

Please propose improvements through issues and pull requests in this repository so that development stays with the project.

Read [LICENSE](LICENSE) and [ASSET-NOTICE.md](ASSET-NOTICE.md) before contributing. The project is all rights reserved; public visibility does not grant independent reuse permission. Obtain any permission needed for your contribution from the relevant rights holder.

Do not add third-party artwork, logos, or other material without permission from its owner. Credit does not replace permission. Contributions must identify their authors and any applicable third-party terms.

For code changes, run:

```sh
npm run check
npm run build
```
